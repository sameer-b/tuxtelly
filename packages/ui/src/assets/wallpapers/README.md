# Bundled 4K wallpapers

These four local JPEGs were downloaded from Unsplash and cropped to 3840 × 2160
for TuxTelly's optional TV home-screen wallpaper presets. The photos are used
under the [Unsplash License](https://unsplash.com/license). They are bundled so
the presets work offline and do not contact an image host at runtime.
